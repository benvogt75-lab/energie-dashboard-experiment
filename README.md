# Gebäudemanagement-Experiment V2.0 – geräteübergreifender Pilot

**Öffnen:** `index.html` im Desktop-Browser oder – für iPhone/Android empfohlen – die Dateien unverändert auf einem HTTPS-Webserver (z. B. GitHub Pages) bereitstellen und den Link in Safari/Chrome öffnen.

## Änderungen gegenüber V1.9
- Responsive Anpassungen für kleine Displays, Querformat und Tablets.
- Touch-Ziele und Fokusmarkierung optimiert; iOS-Eingabezoom vermieden.
- Breiten- und Scroll-Probleme an Navigation, Tabellen und Kacheln reduziert.
- Im Export werden grobe Eingabegeräteklasse und Browserfenstergröße mitgespeichert; **kein Betriebssystem oder exakter Gerätetyp wird erfasst**.
- Aufgaben, Antwortschlüssel, Likert-Items, Energiedaten und beide Bedienkonzepte bleiben unverändert.
- Separater lokaler Speicherstand (`v20`).

## Grenzen
Diese Version wurde statisch und syntaktisch geprüft, aber **nicht auf realen iPhones/Samsung-Geräten oder per Browser-End-to-End-Test**. Eine geräteübergreifende Funktionsgarantie ist daher nicht möglich. Es handelt sich weiterhin um eine **lokale Pilotversion** ohne zentralen Ergebnis-Upload, ohne Einwilligungsprozess und ohne produktive Studiendatenbank.

## Pretest
1. Auf iPhone in Safari, Android in Chrome und Laptop im Browser über denselben HTTPS-Link öffnen.
2. Beide Varianten im Demomodus in Hoch- und Querformat aufrufen; Navigation und Assistent testen.
3. Im Pilotmodus fünf Aufgaben und zehn Items abschließen; JSON-Export prüfen.
4. Darauf achten, dass kein Text abgeschnitten ist, die Tastatur das Eingabefeld nicht dauerhaft verdeckt und kein horizontales Seitenscrollen erforderlich ist.
5. Fehler inklusive Gerät, Browser, Orientierung und Screenshot dokumentieren.
